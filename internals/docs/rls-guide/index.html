行レベルセキュリティ（RLS）実践ガイド

PostgreSQL 18

対象: SQL は書けるが、行レベルセキュリティ（RLS）はこれから使う人

PostgreSQL の行レベルセキュリティ（RLS）を、実際に psql で動かしながら身につける実践ガイド。所有者ベースの最小例からマルチテナント、はまりどころまでを、入力と実行結果をセットで追う。上から順にコマンドを打っていけば、RLS の設計・実装・トラブル切り分けの 8 割を自力でこなせるようになる。所要時間の目安は 40〜60 分。掲載コマンド・出力はローカルの PostgreSQL ビルドで検証済み（RLS は PostgreSQL 9.5 以降で共通の挙動）。

第1章 RLS でできること 行単位でアクセスを絞る仕組みと、GRANT との違い・使いどころを掴む。 第2章 準備 検証用のデータベース・ロール・サンプルテーブルをコピペで用意する。 第3章 まず動かす（最短ルート） RLS を有効化して 1 つポリシーを作り、見え方が変わることを確認する。 第4章 ポリシーを正しく書く USING と WITH CHECK、コマンド別・ロール別、PERMISSIVE と RESTRICTIVE を使い分ける。 第5章 実践：マルチテナントを作る 接続プール前提で、セッション変数によるテナント分離を組む。 第6章 つまずきポイントと対処 所有者バイパス・デフォルト拒否・GRANT との二層など、はまりどころを潰す。 第7章 まとめとチートシート コマンド早見表と、導入前の設計チェックリスト。
行レベルセキュリティ（RLS）実践ガイド — 実行例はローカルの PostgreSQL ビルドで検証（RLS は 9.5 以降で共通の挙動）
