pgbench カスタムスクリプト実践ガイド

PostgreSQL 18 · 2026-07-29

対象: pgbench -i / -c / -T は使えるが、-f で自前のシナリオを書くのはこれからという方

組み込みの tpcb-like では測れないワークロードを、自分で書いたスクリプトで測れるようになるためのガイド。\set と式・乱数分布・\gset・条件分岐・パイプラインといったカスタムスクリプトの全機能を、実際に動く例と実測した出力で一つずつ確認していく。最後まで手を動かすと、読み書きを混ぜた現実的なワークロードを組み、スクリプト別・ステートメント別に結果を読み解けるようになる。所要時間の目安は 2〜3 時間。本文中の出力はすべて PostgreSQL 18.4 上で実際に実行して採取したもの（tps や latency は環境で変わる）。

第1章カスタムスクリプトでできること組み込みスクリプトの限界を確認し、カスタムスクリプトの構成要素と重み付けの全体像をつかむ。 第2章準備以降すべての章で使う bench データベースを用意し、実行コマンドの基本形を決める。 第3章まず動かす（最短ルート）最小のスクリプトを書いて実行し、出力の読み方と :scale の罠を実測で確認する。 第4章変数と式を使いこなす\set の式・自動変数・4つの乱数分布・permute() を、debug() と実測で確かめながら覚える。 第5章メタコマンドで制御する\gset で結果を受け取り、\if で分岐し、パイプラインで往復を減らす。 第6章実践：現実的なワークロードを組む読み9:書き1のミックスを組み、スクリプト別レポート・プロトコル比較・ログ分析まで通す。 第7章つまずきポイントと対処実際のエラーメッセージから原因を切り分け、「数字が信用できない」パターンを見抜く。 第8章まとめとチートシートメタコマンド・関数・オプションの早見表と、計測手順の型。
