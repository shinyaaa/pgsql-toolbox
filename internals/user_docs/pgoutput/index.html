pgoutput 実践ガイド

PostgreSQL 16 · 2026-08-06

対象: SQL と psql は使えるが、論理デコーディングや pgoutput は触ったことがない方

pgoutput は PostgreSQL に標準で組み込まれている論理デコーディング出力プラグインで、 論理レプリケーションと CDC（変更データキャプチャ）の共通の入口である。 このガイドを上から順に読み、示したコマンドを実行していけば、 pgoutput の出力を自分で取り出し、中身を読み、オプションで制御できるようになる。 第2章で作る環境を第8章まで引き継ぐので、途中で作り直す必要はない。 所要時間はハンズオンを実際に打ちながらで 2〜3 時間程度。 本文中の出力はすべて PostgreSQL 16.13 上で実際に実行して採取したものである （LSN・xid・OID・タイムスタンプは環境ごとに異なる）。

第1章 pgoutput でできること pgoutput が何者で、どこで使われ、何を解決するのかを掴む。 第2章 準備 wal_level・サンプルテーブル・パブリケーション・スロットを、コピペで用意する。 第3章 まず動かす — 3 分で出力を見る SQL 関数と pg_recvlogical で、pgoutput の出力を実際に取り出す。 第4章 出力メッセージを読む Relation / Insert / Update / Delete などの中身をバイト単位で読み解く。 第5章 pgoutput のオプション proto_version・binary・messages・streaming・two_phase・origin を1つずつ試す。 第6章 送る内容をパブリケーションで絞る publish・行フィルタ・列リスト・パーティションで、流れるデータを制御する。 第7章 実践: 論理レプリケーションと CDC CREATE SUBSCRIPTION の裏で pgoutput がどう呼ばれているかを、目で確かめる。 第8章 つまずきポイントと対処・チートシート よく出るエラーと復旧手順、そして最後に早見表。
